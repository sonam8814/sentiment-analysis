# sentiment-analysis

# 🌿 Emerald NPS: AI-Powered Sentiment Analytics

A high-performance and modern NPS (Net Promoter Score) intelligence dashboard built with **Streamlit**.  
This platform transforms raw customer feedback into actionable business insights using **Aspect-Based Sentiment Analysis (ABSA)**, anomaly detection, and AI-powered analytics.

---

# ✨ Features

- 🎨 Premium Emerald + Graphite dark UI
- 📊 Interactive analytics dashboard
- 🤖 AI-powered sentiment analysis
- 🧠 Aspect-Based Sentiment Analysis (ABSA)
- 🚨 Toxic promoter detection
- 🔒 PII redaction for privacy
- ⚡ Fast LLM processing using Groq/Gemini APIs
- ☁️ Real-time Supabase backend integration
- 📈 Beautiful visualizations using Plotly

---

# 🧠 Aspect Categories

The AI automatically classifies customer feedback into categories such as:

- Professionalism
- Responsiveness
- Value for Money
- Quality of Service

---

# 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Streamlit | Frontend Dashboard |
| Supabase | Database & Backend |
| Groq / Gemini API | AI Processing |
| Plotly | Charts & Visualizations |
